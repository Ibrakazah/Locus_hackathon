# LOCUS Hackathon 2026 · Кейс 2 — Персональный маршрут поступления

Скелет проекта. Стек: **Next.js 16 (App Router) · TypeScript · Tailwind v4 · React 19**.

## Команда и разделение ролей

Каждая роль — свой модуль. Работайте параллельно, не трогая чужие файлы.

| Роль | Где работаем | Что делает |
|---|---|---|
| **UI (Ибрахим)** | `src/app/**`, `src/components/ui/**` | Страницы, дизайн-система, вёрстка, UX |
| **flow** | `src/lib/flow/**`, `src/app/onboarding/steps/**` | Визард, шаги, state machine, прогресс, roadmap |
| **engine** | `src/lib/engine/**` | Скоринг профиля, матчинг вузов (чистые функции) |
| **data** | `src/lib/data/**` | Вузы, программы, дедлайны, пороги баллов |

### Как устроены модули

```
src/
├── app/                     # UI — маршруты и страницы
│   ├── page.tsx             # лендинг
│   ├── onboarding/          # визард (5 шагов)
│   │   └── steps/           # рендер каждого шага (UI)
│   ├── results/             # диагностика + подбор вузов
│   ├── roadmap/             # таймлайн и чек-листы
│   └── api/universities/    # API-роут
├── components/ui/           # дизайн-система (Button, Card, Slider…)
└── lib/
    ├── engine/              # РОЛЬ ENGINE: profile.ts, scoring.ts, matching.ts
    ├── flow/                # РОЛЬ FLOW: wizard.ts, steps.ts, progress.ts
    └── data/                # РОЛЬ DATA: universities.json, index.ts, types.ts
```

## Критерии КЗ (ЕНТ-2026) и порядок вопросов

Визард построен на официальных правилах приёма в ОВПО РК. Источники: Типовые правила приёма (МНВО РК), testcenter.kz, egov.kz.

### Структура ЕНТ (максимум 140 б)

| Блок | Заданий | Баллы | Минимум по предмету |
|---|---|---|---|
| История Казахстана | 20 | до 20 | 5 |
| Математическая грамотность | 10 | до 10 | 3 |
| Грамотность чтения | 10 | до 10 | 3 |
| Профильный предмет 1 | 40 | до 50 | 5 |
| Профильный предмет 2 | 40 | до 50 | 5 |

Провал минимума по одному предмету снимает результат с конкурса, даже если сумма 100+. Комбинацию профильных предметов нельзя менять в течение года.

### Пороги участия (2026)

- Национальные вузы — **65**, остальные — **50**
- Педагогические науки и Право — **75**, Здравоохранение — **70**
- Сельское хозяйство / ветеринария — **50**; колледж (сокращённая ОП) — **25**
- Реальный «проходной» по гранту выше порога: медицина 111–136, топ-IT/международные отношения 100+.

### Порядок шагов визарда

1. **Кто ты** — класс/статус (10, 11, колледж, выпускник прошлых лет), город, язык обучения
2. **Баллы ЕНТ** — реальные или прогноз, 5 полей под максимумы, выбор комбинации профильных предметов (13 официальных комбинаций), предупреждение о минимумах по предметам
3. **Направление подготовки** — группа образовательных программ, подсказка совместимости с выбранной комбинацией ЕНТ, творческий экзамен для творческих
4. **Грант или платно** — форма финансирования, право на квоту (сельская молодёжь/сироты/инвалиды), потолок оплаты ₸/год
5. **Ограничения** — регион, общежитие, военная кафедра

Реализация в `src/lib/engine/profile.ts` (типы, ENT_MAX/ENT_MIN, комбинации, пороги направлений), `src/app/onboarding/steps/*` (рендер), `matching.ts` (пороги/блокеры).

## Задачи по ролям (начните здесь)

**data:** добавить вузы в `src/lib/data/universities.json` (2–5/день человеку). Поля — в `types.ts`. Источники: официальные сайты, `egov.kz` (пороги), `testcenter.kz` (ЕНТ). Особое внимание — реальным `grantMinScore` (проходным прошлого года) по группам программ.

**engine:** улучшить `scoring.ts` (перцентили по реальным данным конкурса грантов) и `matching.ts` (квоты по областям, целевые гранты Мангистау, учёт «сельской молодёжи», творческие специальности).

**flow:** Progression XL в `progress.ts` (XP/уровни), шаги визарда, валидация по шагам, напоминания о дедлайнах.

**UI (Ибрахим):** дизайн-система в `components/ui`, редизайн страниц, пустые состояния, мобильная вёрстка, шрифты, иконки.

## Важные правила кейса

- Не врать про данные и скорость. Дедлайны — из официальных источников, со ссылкой.
- Продукт, а не чат. Это интерактивный дашборд-маршрут.
- Дизайн LOCUS не копируем. Оценка: путь 30%, UX/UI 25%, персонализация 20%, стабильность 15%, техника 10%.
